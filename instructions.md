# Assistant Instructions

These instructions apply to every request made in this repository unless the user explicitly overrides them.

## Default behavior

1. Read this file before acting on each new request.
2. Inspect the relevant project files before making assumptions or changes.
3. Make precise, minimal changes that fully address the request.
4. Preserve existing behavior unless a change is explicitly requested.
5. Follow the project's existing structure, naming, formatting, and tooling conventions.
6. Run the smallest relevant existing validation command after code changes.
7. Clearly report what changed and mention any limitation or validation failure.

## User priority

The user's latest explicit request takes precedence over these defaults, except where it conflicts with higher-priority system or platform requirements.

## Editing rules

- Do not modify unrelated files.
- Do not remove or overwrite existing user changes.
- Do not add dependencies unless they are necessary.
- Do not commit secrets, credentials, or private data.
- Update related documentation when behavior or usage changes.

## Communication

- Ask for clarification when a decision materially affects the implementation.
- Be concise and direct.
- Do not claim work is complete if it is blocked or unverified.
